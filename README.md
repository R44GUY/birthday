# Birthday website 💖

1. Put your photos in `images/` as `1.jpg` … `6.jpg` (or edit the list in `script.js`).
2. Edit the name, wish, reasons and letter at the top of `script.js` (the `CONFIG` block).
3. Optional: add a song as `music.mp3` in this folder.
4. Push to GitHub, then Settings → Pages → Deploy from branch `main` / root.

Open `index.html` directly in a browser to preview.
